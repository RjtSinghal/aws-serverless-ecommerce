# AWS Serverless E-commerce

This project is a **serverless microservices-based e-commerce backend** built to explore modern cloud-native architecture using AWS services.

The system leverages **AWS Lambda, API Gateway, DynamoDB, and S3** to create a scalable and cost-efficient backend without managing servers.

## Key Concepts

- Serverless architecture
- Microservices design
- Event-driven processing
- Cloud-native application development

## Tech Stack

- Node.js
- AWS Lambda
- API Gateway
- DynamoDB
- S3
